# RepoDeck

[English README](README.en.md)

RepoDeck は、複数リポジトリ(複数プロジェクト)のウィンドウ配置を「ワークセット」として
まとめて管理し、グローバルホットキーとクイックスイッチャーで瞬時に切り替えられる
Windows デスクトップアプリです。Codex CLI / VS Code 拡張のライフサイクルフックと連携し、
各ワークセットの AI エージェント実行状況(実行中・入力待ち・完了)をバッジとトレイ
アイコンの色で表示します。

- Rust + [Slint](https://slint.rs) 製、Windows ネイティブ (C#/WPF 非依存)
- 完全ローカル動作。ネットワーク通信・テレメトリーなし
- インストーラー不要。`repodeck.exe` を実行するだけ

![設定画面](docs/screenshots/settings.png)

## インストール

1. [Releases](https://github.com/zappyzed100/repodeck/releases) から
   `RepoDeck-v<version>-windows-x64.zip` をダウンロード
2. 好きなフォルダーへ展開(管理者権限・インストーラー不要)
3. `repodeck.exe` を実行 — タスクトレイにアイコンが常駐します

## 30秒で試す

1. `repodeck.exe` を起動(タスクトレイにアイコンが表示される)
2. トレイアイコンを右クリック →「新しいセットを登録」で、現在開いているフォルダー/
   ウィンドウをワークセットとして登録
3. 別のフォルダーでも同様にもう1つワークセットを登録
4. `Ctrl+Alt+R` (既定のホットキー) を押すとクイックスイッチャーが開く
5. 登録した2つのセットが一覧表示されるので、クリックまたは数字キー(`1`, `2`...)で
   切り替え — 選択中でないセットのウィンドウは自動的に退避(最小化 or 固定枠へ)

## 使い方

### ワークセットの登録

タスクトレイメニューの「新しいセットを登録」、またはクイックスイッチャーの
「セット管理を開く」からセット管理画面を開き、フォルダーを選択します。フォルダーの
親方向に `.git` が見つかればそのルートを、なければ選択したフォルダー自体を
リポジトリとして登録します。現在画面に表示されているウィンドウのうち、登録したい
ものにチェックを入れて保存すると、その配置(位置・サイズ・最大化状態)が記録されます。

### クイックスイッチャー

- 既定のホットキー: `Ctrl+Alt+R` (設定画面から変更可能)
- ホットキーまたはトレイアイコンの左クリックで表示/非表示をトグル
- 検索ボックスに入力してセット名・リポジトリパスで絞り込み
- ↑/↓ + Enter、数字キー (`1`-`9`) での直接切替、マウスクリックにも対応
- Esc で閉じる。設定でフォーカスを失ったときに自動的に閉じるようにもできる

### 設定画面

トレイメニューの「設定」から開けます。

- **ホットキー**: 修飾キー(Ctrl/Alt/Shift/Win)とキーを選んで保存。他アプリと
  衝突する場合は自動的に元のホットキーへロールバックされ、その旨を表示します
- **Codex連携**: 下記参照
- **起動設定**: Windows起動時にRepoDeckを自動起動するかを切り替え
- **バージョン情報**: バージョン表示とサードパーティ表示(ライセンス一覧)

### Codex連携のセットアップ

RepoDeck は Codex を起動したり接続したりしません。Codex CLI / VS Code 拡張が持つ
ライフサイクルフックの通知先として、同梱の `repodeck-hook.exe` を登録することで、
各ワークセットのリポジトリでの Codex 実行状況をクイックスイッチャーのバッジと
トレイアイコンの色に反映します(実行中=青、入力待ち=黄、完了=緑)。

![Codexバッジの例](docs/screenshots/quick-switcher-agent-badge.png)

設定画面の「Codex連携」セクションで、以下の手順を行います。

1. 「hook実行ファイルを確認」で `repodeck-hook.exe` が同じフォルダーにあるか確認
2. 「hooks.json断片をコピー」でクリップボードへ設定断片をコピー
3. Codex の設定フォルダー(「Codex設定フォルダーを開く」で開けます)にある
   `hooks.json` へ、コピーした内容を貼り付け
4. Codex CLI で `/hooks` を実行し、追加された4つのフックをレビューして信頼する
5. Codex を再起動、または設定を再読み込み
6. 設定画面の「テストイベントを送信」で疎通確認(登録済みのセットが1つ以上必要)

**注意**: Codex CLI の `/hooks` で4つのフックを信頼するまで、イベントは届きません。

### 全ウィンドウ回収 / 復旧

- トレイメニューの「全管理ウィンドウを回収」: 登録済みの全ウィンドウをメイン画面へ
  強制的に集約する緊急操作です
- 切替の途中で RepoDeck が異常終了した場合、次回起動時に「前回の切替が中断されました」
  というダイアログが表示され、元の配置に戻す/全ウィンドウをメイン画面へ回収/何もしない
  のいずれかを選べます
- モニター構成が変わった(切断など)結果、画面外になってしまったウィンドウは自動的に
  最小化されます

## 既知の制約 (MVP)

- Windows 専用。仮想デスクトップ機能は使用していません
- 管理者権限で起動されたウィンドウは操作を拒否します(セキュリティ境界のため)
- Windows トースト通知、`hooks.json` の自動編集、署名付きインストーラー、自動更新は
  未対応(将来のバージョンでの対応を予定)
