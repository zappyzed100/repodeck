## 用語

- **メイン画面**: アクティブなセットの窓を表示する画面。複数モニタで構成されうる（現状 DISPLAY1＋DISPLAY2）。
- **サブ退避先（サブ画面）**: 特定セット専用の退避エリア（例: 「動画」=DISPLAY6全画面、「モニター」=DISPLAY3の左右2分割）。
- **一般退避先モニタ**: メインでもサブでも除外でもないモニタ。
- **除外モニタ**: メイン・サブ・退避のいずれにも**一切使わない**。
- **セット**: 1つ以上の窓を持つ作業単位。

---

## 1. アクティブなセット（メインに表示）

窓ごとに、**登録情報（保存された位置・サイズ）があるかどうか**で分岐する。

### 1.1 登録情報がある場合 … 案B（登録位置を復元）
- その窓は、**登録した時の位置・サイズ（相対位置）に復元**する。アルゴリズム整列はしない。
- 「1画面1窓・全画面」にしたい場合は、**登録時にその配置で登録**しておく（各窓を各メインモニタに全画面で置いた状態で登録）。

### 1.2 登録情報がない場合（セットから起動した直後など） … アルゴリズムで均等配置
- 保存された位置が無い窓は、**メイン画面を最大限に使って**自動配置する。
- **登録されたアプリを左から順に**並べる。
- **なるべく均等になるように**割り当てる（メインが複数モニタなら、退避と同じ「窓が最大になるように・均等に」＝§2.2/§2.3/§2.5 と同じ分割・選択ルールをメイン画面群に適用）。
  - 例: メイン2画面・窓2枚 → 1画面1窓の全画面。窓が多ければ各モニタ内を均等グリッドで分割。

→ まとめ: **保存位置があれば復元、無ければ「画面を最大活用・左から・均等」で自動配置**。

## 2. 非アクティブなセットの退避

非アクティブなセットの窓を一般退避先モニタへ退避する。

### 2.1 容量と最小化
- **1モニタあたりの最大分割数**: **QHDクラス=6分割 / HDクラス=4分割**。
- **「全部を退避先に並べる」わけではない**。退避先の容量が尽きたら、**余りは最小化**する。

### 2.2 分割の入れ方（窓を追加していく順序）
モニタに窓を追加していくとき、次の順で**均等セル**に入れる（余ったセルは空のまま）:

- **HD（最大4）**: 1分割 → 2分割 → 4分割(3つ使用) → 4分割
- **QHD（最大6）**: 1分割 → 2分割 → 4分割(3つ使用) → 4分割 → 6分割(5つ使用) → 6分割

→ セルは**すべて同じ大きさ**で、先頭からN個に入れる（例: 3窓なら4分割のうち3セルを使い、1セルは空）。
→ 分割は**なるべく正方形に近くなる**ように行う（2分割=縦2列、4分割=2×2、6分割=3×2）。

### 2.3 窓の大きさ表（事前計算しておく）
状態ごとの1窓のサイズを事前に計算して表を持つ。

**HD 1920×1080**

| 窓数 | 1窓のサイズ |
|---|---|
| 1 | 1920×1080 |
| 2 | 960×1080 |
| 3 | 960×540 |
| 4 | 960×540 |

**QHD 2560×1440**

| 窓数 | 1窓のサイズ |
|---|---|
| 1 | 2560×1440 |
| 2 | 1280×1440 |
| 3 | 1280×720 |
| 4 | 1280×720 |
| 5 | 853×720 |
| 6 | 853×720 |

### 2.4 既存の窓が縮む処理（現状バグ）
- 窓を追加してモニタの分割数が変わるとき（例: 1分割→2分割、2分割→3窓で4分割）、**先に入っていた窓も新しい（小さい）サイズに縮む**必要がある。
- **現状はこの「既存窓の縮小・再配置」が発動していない** → 先に入っていた窓が古いサイズのまま残り、重なる／はみ出す。ここを直す。

### 2.5 退避先モニタの選び方（＝窓が最大になるように選ぶ）
- 窓を1つ退避させるとき、退避先モニタは **「そこに入れたときの窓の大きさが最大になる」ように決定する**。
  - 具体的には、各候補モニタについて「その窓を追加した後の（そのモニタの）1窓サイズ」を 2.3 の表で引き、**最大になるモニタ**を選ぶ。
  - 空きモニタは「全画面（=最大）」になるので最優先。すべてのモニタに1つ以上入った後は、**追加後のセルが最も大きくなるモニタ**へ。
- この結果として、複数の退避先モニタに**バランス良く**分散する（片方が空いている＝そこに入れれば大きくなるのに、もう片方を細かく割ることはしない）。

### 2.6 重なり・一貫性
- 窓の上に窓が乗ってはいけない（**重なり禁止**）。
- 切替後も配置が保たれ、ズレ・重なり・サイズ不整合が起きない。

## 3. サブ指定セット

- サブ画面を指定されたセットは、一般退避先ではなく**指定サブ画面**へ退避する。
- サブを複数セットで共有する場合、サブ領域をセット数で分割（重なり・隙間なし）。
- **1セットで複数窓**がサブに入るときは、割り当てられたサブのセル内をさらに分割する。
  - 分割は**基本的に正方形に近くなるように**行う。

---

## 4. 「メイン画面を空にする」

- 登録済みの窓を**すべて退避**（メインに1つも残さない）。
- サブ指定セットはサブへ、それ以外は一般退避先へ（第2項のルール）。
- 退避先が足りない窓は最小化。

## 6. 現状仕様との差分（実装で直すべき点）

1. **分割形状の変更**: 現状の3分割は「半分＋1/4×2」だが、確定仕様は「**4分割のうち3セル使用（全部同じ大きさ）**」。5分割も同様に「6分割のうち5セル使用」。→ 均等グリッド＋先頭N個使用に変更。
2. **既存窓の再配置（縮小）**: 分割数が増えたとき、先に入っていた窓も新サイズへ再配置する（現状発動せず＝重なり・サイズ不整合の主因）。
3. **容量超過の最小化**: HD4/QHD6を超える分は最小化（全部は並べない）。
4. メイン配置は**案B（登録位置の復元）**のままでよい（アルゴリズム整列はしない）。
